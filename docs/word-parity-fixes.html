Word Render/Layout Parity Fixes

The frames are cropped into the problem area rather than full-page screenshots. Baseline images live under artifacts/baseline/ and are intentionally not committed.

DOCX table import preserves structure Repro: tests/repros/word/table-import-preserves-structure.docx Fix commit: ca4e9e0
Word keeps A1/B1 on the same row and A2/B2 on the next row.
Before: browser import flattened table cells into ordinary paragraphs; B1 stacked under A1 at x=0.
After: browser import emits table objects, so same-row cells share Y and distinct X positions.

Fix: Processors.forEditorPackage now uses the typed DOCX-to-editor package path, including tables, headers/footers, page setup, and numbering.

  • Before guard: B1 x=0, y=150.4
  • After guard: B1 x=318, y=142.7

Default paragraph after-spacing inside table cells Repro: tests/repros/word/table-cell-default-after-spacing.docx Fix commit: c05cf8d
Word applies the Normal paragraph after-spacing in table cells when the DOCX omits explicit spacing.
Before: cell paragraph spacing was forced to zero, compressing the second row and following paragraph.
After: omitted spacing remains inherited/defaulted; row positions move down to match Word's cell paragraph rhythm.

Fix: preserve missing DOCX w:spacing/@after as None, and stop clearing table-cell paragraph SpacingAfter in layout style normalization.

  • Before guard: Gamma y=160.6, After y=188.5
  • After guard: Gamma y=170.6, After y=208.5
  • Regression check: row gap should stay roughly one default after-spacing larger than the pre-fix baseline.
Native Word text size uses CSS-pixel scale Repro: tests/repros/word/table-cell-default-after-spacing.docx Fix commit: this commit
Word renders 11 pt Calibri as roughly 14.7 CSS pixels on the page surface.
Before: native measurement and glyph drawing passed Word point sizes directly to ../renderer, shrinking Calibri text.
After: native measurement and glyph drawing use the same 96/72 point-to-pixel conversion as the browser canvas path.

Fix: convert Word paint-command font sizes from points to canvas pixels before calling Renderer.Text.measureWidth and Renderer.Text.layout in word-native.

  • Before guard: native Calibri body text was visibly smaller than Word/browser.
  • After guard: native body text scale matches the browser path and the Word reference more closely.
  • Check with tools/native-runner on the focused repro.
Static runner captures omit editor caret Repro: tests/repros/word/table-cell-default-after-spacing.docx Fix commit: this commit
Word print/PDF reference has no active editor caret in the rendered page.
Before: browser and native snapshot runners captured the initial collapsed selection as a blue caret.
After: automated snapshots clear selection before reading layout JSON or taking screenshots.

Fix: add a browser clearSelection API for capture tools and import native runner documents with Selection = None.

  • Before guard: blue caret appeared in browser/native PNG artifacts.
  • After guard: static parity artifacts match Word’s non-editing render surface.
  • Interactive editor behavior is unchanged outside the snapshot runners.
