Phase 1 Feature Test - Excel Features

📋 Phase 1: Foundation Features

This test page demonstrates the four core Excel features implemented in Phase 1.

1. Range References in Formulas NEW

  • Cells A1-A5 contain numbers 100, 200, 300, 400, 500
  • Cell A6 contains =SUM(A1:A5) - should show 1500
  • Cell B1 contains =AVERAGE(A1:A5) - should show 300
  • Try creating your own range formulas like =SUM(B1:B10)

2. Copy/Paste/Cut NEW

  • Select cell A1 and press Ctrl+C (or Cmd+C on Mac) to copy
  • Select cell D1 and press Ctrl+V to paste - formula references adjust automatically
  • Try Ctrl+X to cut a cell
  • Formula Adjustment: Copy cell A6 (=SUM(A1:A5)) and paste to E6 - formula becomes =SUM(E1:E5)

3. More Functions NEW

  • COUNT: Cell C1 has =COUNT(A1:A5) - counts non-empty cells (should be 5)
  • MIN: Cell C2 has =MIN(A1:A5) - finds minimum (should be 100)
  • MAX: Cell C3 has =MAX(A1:A5) - finds maximum (should be 500)
  • IF: Cell C4 has =IF(A1>150, "High", "Low") - conditional logic (should be "Low")
  • Try changing A1 to 200 - C4 should update to "High"

4. Undo/Redo NEW

  • Edit any cell and press Ctrl+Z (or Cmd+Z) to undo
  • Press Ctrl+Y (or Cmd+Y) to redo
  • Try a sequence: Edit cell → Copy → Paste → Undo → Undo → Redo
  • History supports up to 50 operations

Basic Operations (Pre-existing)

  • Click a cell to select it
  • Double-click or press Enter/F2 to edit
  • Use arrow keys to navigate
  • Press Tab to move to the next cell
  • Press Delete or Backspace to clear a cell
