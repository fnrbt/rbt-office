XLSX Import Test - office-format Integration

📊 XLSX Import Feature

This test page demonstrates importing Excel files using the office-format library integration.

office-format Integration NEW

  • File Upload: Select an .xlsx file to import
  • Sheet Selection: Choose which sheet to import (or first sheet)
  • Data Import: Cell values, formulas, styles all imported
  • Style Preservation: Bold, italic, colors, font sizes preserved
  • Layout Import: Column widths and row heights preserved
  • Undo Support: Import is undo-able with Ctrl+Z

Supported Cell Types

  • Numbers: Imported as numeric values
  • Strings: Imported as text
  • Booleans: TRUE/FALSE values
  • Dates: Excel date serials
  • Formulas: Formula text imported (re-evaluated in grid)

Supported Styles

  • Font: Bold, Italic, Size, Color
  • Background: Fill color
  • Number formats: Currency, Percentage, Date, Decimal
  • Column widths (converted to pixels)
  • Row heights (converted to pixels)

How to Use

  1. Click "Choose File" and select an Excel .xlsx file
  2. If file has multiple sheets, select which sheet to import
  3. Click "Import XLSX" to load the data
  4. Data will appear in the spreadsheet with formatting preserved
