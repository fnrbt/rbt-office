Fable Spreadsheet Test

Instructions

  • Click a cell to select it
  • Double-click or press Enter/F2 to edit
  • Use arrow keys to navigate
  • Press Tab to move to the next cell
  • Press Delete or Backspace to clear a cell
  • Enter formulas starting with = (e.g., =A1+B1, =SUM(A1,A2,A3))
  • Formatting: Select cell A5 and try the toolbar buttons (Bold, Italic, Underline, Font size, Colors, Alignment)
  • Number formats: Select a number cell and try currency or percent formatting
