Phase 3 Feature Test - Polish

✨ Phase 3: Polish Features

This test page demonstrates the four polish features implemented in Phase 3.

1. Row/Column Resizing NEW

  • Infrastructure added: Model supports custom RowHeights and ColumnWidths maps
  • Functions: getRowHeight, setRowHeight, getColumnWidth, setColumnWidth
  • Future: Drag dividers between headers to resize (UI implementation pending)

2. Find/Replace NEW

  • Use the search controls below to find text in cells
  • Find: Enter search term and click "Search" to find all matches
  • Find Next: Navigate through results
  • Replace: Replace current selection with new text
  • Replace All: Replace all occurrences at once
  • Case-sensitive option available
  • Searches both cell values and formulas

3. Conditional Formatting NEW

  • Use the buttons below to apply conditional formatting rules
  • Rule Types: Greater Than, Less Than, Equal To, Between, Contains Text
  • Cells B1-B5 have values 100-500 (perfect for testing number rules)
  • Try "Highlight >300" to highlight cells with values greater than 300
  • Try "Highlight =200" to highlight cells equal to 200
  • Conditional formats override base cell styles

4. CSV Import/Export NEW

  • Export: Click "Export CSV" to download spreadsheet as CSV
  • Import: Paste CSV text and click "Import CSV" to load data
  • Handles numbers, strings, formulas, booleans
  • Escapes commas and quotes properly
  • Import is undo-able with Ctrl+Z

All Previous Features Still Available

  • Phase 1: Range formulas, Copy/Paste, COUNT/IF/MIN/MAX, Undo/Redo
  • Phase 2: Column sorting, Filtering, Number formatting, Insert/Delete rows/cols
